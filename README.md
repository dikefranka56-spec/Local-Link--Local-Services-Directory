# LocalLink — Local Services Directory

A responsive frontend prototype for discovering everyday community services.

## Features
- Search services by name, category, or description
- Category filters and sorting
- Accessible details modal and keyboard Escape handling
- Responsive service cards
- Clearly labelled fictional sample listings

## Run
Open `index.html` in a modern browser. No installation or build step required.

## Important
All service providers are fictional examples. The directory does not verify, endorse, or connect users to real businesses.
